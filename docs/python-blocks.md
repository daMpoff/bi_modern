# Python-блоки

Внутри блока доступны Polars DataFrame `df`, модуль `pl` и строки `rows`. Запишите итоговую таблицу или список словарей в `result`. Для старых скриптов исполнитель также поддерживает результат через `df` или `rows`.

```python
result = df.group_by("region").agg(pl.col("sales").sum())
```

API и Celery отправляют таблицу по HTTP внутреннему брокеру. На каждый запрос брокер запускает одноразовый Linux-контейнер и возвращает таблицу в формате Arrow IPC. Если брокер недоступен, блок сообщает об ошибке.

## Запуск на Windows с Docker

Потребуется Docker с Linux-контейнерами, cgroup v2, seccomp и поддержкой лимитов CPU, памяти, swap и числа процессов. Брокер проверяет эти возможности при старте. Используйте один брокер на Docker daemon. Команды ниже выполняются из корня ERGO MS.

```powershell
./virtual_env/python/Scripts/python.exe modules/bi_analysis_modern/sandbox/manage.py up
```

Команда собирает образы брокера и исполнителя, запускает брокер на `127.0.0.1:8766` и проверяет его готовность. При первом запуске она записывает адрес и случайный токен в `env/bi-python.env`. Последующие запуски используют тот же токен. Перезапустите API и Celery, чтобы ядро перечитало окружение. Для остановки выполните команду с `down`.

Если API или Celery тоже работают в контейнерах, задайте им доступный из их сети `BI_PYTHON_EXECUTOR_URL` и один и тот же `BI_PYTHON_EXECUTOR_TOKEN`. В общей приватной сети Compose брокер может быть доступен как `http://broker:8766`. Доступ к Docker socket нужен только брокеру. Ограничьте его адрес внутренней сетью, а для удалённого соединения используйте HTTPS.

## Лимиты одного запуска

| Ресурс | Лимит |
| --- | --- |
| Время | 20 секунд общего времени, 10 секунд CPU, одно ядро |
| Память и процессы | 512 МиБ без дополнительного swap, до 32 процессов и потоков |
| Временное хранилище | 16 МиБ в `/tmp`, 8 МиБ в `/dev/shm` |
| Код и таблицы | До 64 КиБ кода, до 32 МиБ на вход и столько же на результат |
| Параллельность брокера | Два запуска. При занятости обоих исполнителей запрос можно повторить позже. |

Контейнер работает под UID 65534 с корневой файловой системой только для чтения и отключённой сетью. Docker удаляет capabilities, запрещает повышение привилегий и применяет seccomp. Файлы проекта, секреты API и Docker socket остаются на стороне хоста. Дисковый журнал вывода задачи отключён.

За временем выполнения следят брокер и отдельный процесс PID 1 в контейнере. При тайм-ауте завершается вся задача с потомками. Брокер при старте очищает оставшиеся контейнеры с меткой `bi-modern.python-job=true`. [Ограничения ресурсов Docker](https://docs.docker.com/engine/containers/resource_constraints/) · [Linux PID namespaces](https://man7.org/linux/man-pages/man7/pid_namespaces.7.html)

## Проверка

Тесты протокола и авторизации HTTP можно запустить отдельно от Docker.

```powershell
./virtual_env/python/Scripts/python.exe -m unittest modules.bi_analysis_modern.sandbox.test_executor -v
```

Чтобы включить проверки в реальных контейнерах, сначала запустите брокер командой `up`.

```powershell
$env:BI_PYTHON_INTEGRATION = '1'
./virtual_env/python/Scripts/python.exe -m unittest modules.bi_analysis_modern.sandbox.test_executor -v
```
